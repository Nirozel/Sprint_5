Тестирование сервиса "Доска"
добавлены локаторы в файле Locators 
файл conftest находится в директории тестов, потому что, находясь в корневой директории, тесты падали ошибкой запуска 
Написаны автотесты: 

1. Регистрация пользователя
✅ Успешная регистрация
❌ Регистрация с некорректным email
❌ Регистрация уже существующего пользователя

2. Авторизация (Login/Logout)
✅ Успешный вход
✅ Выход из системы (Logout)

3. Создание объявлений
✅ Создание объявления авторизованным пользователем
❌ Попытка создания объявления без авторизации
